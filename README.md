# Industrial Tawjihi Average Calculator

A Java Swing application designed to calculate the average of Industrial Tawjihi students based on subject marks and their official weights.

## Features
- Enter subject marks.
- Calculate the final average automatically.
- Simple and user-friendly graphical interface.

## Technologies Used
- Java
- Java Swing
- NetBeans

## Purpose
This project aims to make calculating the Industrial Tawjihi average easier and faster.
